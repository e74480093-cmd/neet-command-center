Android distraction controls

This web app cannot directly block or pause other Android apps. Use Android Digital Wellbeing:

  1. Open Android Settings → Digital Wellbeing & parental controls.
  2. Choose Focus mode.
  3. Select YouTube and Chrome if listed.
  4. Set a study schedule, or switch Focus mode on manually.
  5. Set app timers for extra daily limits.
Focus mode is a built-in pause, not an unbreakable lock. For stronger controls, ask a parent or guardian to help configure Family Link or a reputable blocker. Check permissions and privacy before installing any blocker. Keep the browser hosting this dashboard available during study sessions.

Backup and restore

Data is stored locally in this browser. Export a backup before changing phones or clearing browser data.

Install on Android

For a true home-screen PWA install, the app must be hosted on an HTTPS website. Open that site in Chrome and use menu → Add to Home screen / Install app. This download bundle is not an APK.
